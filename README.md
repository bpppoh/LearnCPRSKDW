# โครงงานเว็บไซต์สื่อการเรียนรู้ปฐมพยาบาลและการกู้ชีพฉุกเฉิน (CPR, GRXABCDE, AED)
**โรงเรียนสุคนธีรวิทย์ — วิชาโครงงาน (ชั้น ม.3/3)**

---

## 📖 ข้อมูลโครงงาน (Project Overview)
เว็บไซต์สื่อการเรียนรู้เชิงปฏิสัมพันธ์ (Interactive Web Application) ด้านการช่วยฟื้นคืนชีพขั้นพื้นฐาน (CPR), การประเมินผู้บาดเจ็บฉุกเฉินระดับมืออาชีพ (GRXABCDE), และการใช้งานเครื่องกระตุกหัวใจไฟฟ้าอัตโนมัติ (AED) ผลงานการสร้างสรรค์ของนักเรียนชั้นมัธยมศึกษาปีที่ 3/3 โรงเรียนสุคนธีรวิทย์

- **สถานศึกษา:** โรงเรียนสุคนธีรวิทย์
- **รายวิชา:** วิชาโครงงาน
- **คุณครูที่ปรึกษาโครงงาน:** คุณครูวิลัยวรรณ
- **คณะผู้จัดทำ (ม.3/3):**
  1. ด.ช. คุณานนท์ อุนทุโร (เลขที่ 4) — หัวหน้ากลุ่ม / ค้นคว้าข้อมูลการแพทย์ฉุกเฉิน & CPR
  2. นาย ธนาธิป ตั้งศุภธวัช (เลขที่ 7) — ผู้พัฒนาส่วนต่อประสานผู้ใช้ (Frontend UI/UX) & Web Audio
  3. ด.ญ. กัญญาพัชร ลือยาม (เลขที่ 16) — ผู้เรียบเรียงเนื้อหาหลักการประเมิน GRXABCDE
  4. ด.ญ. ไอลดา พิณทอง (เลขที่ 18) — ผู้ออกแบบสื่อจำลองเครื่อง AED และขั้นตอนการช็อกไฟฟ้า
  5. ด.ญ. นันท์นภัส แดงบุญมี (เลขที่ 25) — ผู้จัดทำคลังข้อสอบ Quiz & รวบรวมข้อมูลสายด่วน 1669

## 🌟 โครงสร้างและฟีเจอร์เด่นทั้ง 6 หน้าเว็บ

1. **MainPage (หน้าแรก):**
   - แนะนำแนวคิด "4 นาทีทองแห่งชีวิต" (Golden Period Infographic)
   - สรุป 3 ขั้นตอนสำคัญเมื่อพบคนหมดสติ: ปลอดภัย > ปลุกเรียก & 1669 > ปั๊มหัวใจ/AED
   - Bento Navigation Grid สไตล์โมเดิร์น 21st.dev
2. **CPR (การกู้ชีพขั้นพื้นฐาน):**
   - ทฤษฎี CAB, ข้อเปรียบเทียบระหว่าง Hands-Only CPR vs Conventional CPR (30:2)
   - 5 หัวใจสำคัญของการกดหน้าอกคุณภาพสูง (High-Quality CPR) และข้อควรระวัง Do's & Don'ts
   - **⚡ Interactive CPR Metronome:** เครื่องเคาะจังหวะฝึกกด 100-120 BPM พร้อมเสียงบี๊บสังเคราะห์ผ่าน Web Audio API และไฟกระพริบตามจังหวะ
3. **GRXABCDE (หลักการประเมินผู้บาดเจ็บฉุกเฉิน):**
   - ระบบการประเมิน 8 ลำดับตามมาตรฐานการแพทย์ฉุกเฉิน PHTLS / สพฉ. 1669
   - **⚡ Interactive Step-by-Step Card Flow:** คลิกเลือกดูทีละตัวอักษร (G, R, X, A, B, C, D, E) พร้อม Action Checklist, เหตุผลทางการแพทย์, และคำเตือนอันตรายถึงชีวิต
4. **AED (เครื่องกระตุกหัวใจไฟฟ้าอัตโนมัติ):**
   - อธิบายกลไกการทำงานของ AED และความแตกต่างระหว่างคลื่นหัวใจที่ช็อกได้ (VF/pVT) vs ช็อกไม่ได้ (Asystole/PEA)
   - 4 ขั้นตอนมาตรฐานสากล: เปิดเครื่อง > แปะแผ่นขั้ว > วิเคราะห์ > กดปุ่มช็อก
   - **⚡ Interactive Virtual AED Simulator:** หน้าจอจำลองเครื่อง AED เสมือนจริง พร้อมเสียงแนะนำขั้นตอนการแปะแผ่นขั้วและการช็อก
5. **หน่วยงานที่ติดต่อได้เมื่อเกิดเหตุ (Emergency Contacts):**
   - รวบรวมเบอร์โทรศัพท์ฉุกเฉินสำคัญ: สายด่วนการแพทย์ฉุกเฉิน 1669, 191, 199, 1554, 1154, 1196
   - **⚡ One-Click Call / Copy:** กดโทรออกได้ทันทีหรือคัดลอกเบอร์ลง Clipboard
   - คู่มือ 5 ข้อมูลสำคัญที่ต้องแจ้งเมื่อโทร 1669
6. **About Us (เกี่ยวกับโครงงานและผู้จัดทำ):**
   - ข้อมูลโรงเรียนสุคนธีรวิทย์, คุณครูที่ปรึกษา, วัตถุประสงค์ของโครงงาน
   - บัตรข้อมูลสมาชิกกลุ่ม ม.3/3 ทั้ง 5 คน
   - **⚡ Interactive Mini-Quiz:** แบบทดสอบ 5 ข้อ วัดความรู้การช่วยชีวิตฉุกเฉิน พร้อมคำอธิบายทางการแพทย์และเอฟเฟกต์ Confetti ฉลองเมื่อทำคะแนนได้ดี

## 💻 Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS (21st.dev UI Design Benchmark: Bento Grids, Spotlight Cards, Pill Navigation)
- **Icons:** Lucide React
- **Audio Engine:** Web Audio API (Native browser audio oscillator, 100% offline support)
- **Effects:** Canvas-Confetti
- **Architecture:** 100% Frontend Client-Side (No Backend, No Database, Zero Vulnerability)

## 🚀 วิธีการรันโปรเจกต์ (How to Run)

### 1. ติดตั้ง Dependencies (ทำครั้งแรก)
```bash
cd ~/Documents/cpr-aed-school-project
npm install
```

### 2. รันโหมดทดสอบ (Development Server)
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:5173`

### 3. สร้างไฟล์สำหรับเผยแพร่ (Production Build)
```bash
npm run build
```
ไฟล์พร้อมใช้งานจะถูกสร้างไว้ในโฟลเดอร์ `dist/` ซึ่งสามารถนำไปอัปโหลดขึ้น **GitHub Pages**, **Vercel**, หรือ **Netlify** ได้ฟรีทันที!
